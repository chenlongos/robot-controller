# 测试设计文档

## 一、测试概述

本文档定义了机器人系统的测试策略、测试用例和测试流程，确保系统满足功能需求和性能要求。测试分为三个层次：**单元测试**、**集成测试**和**系统测试**。

## 二、测试策略

### 2.1 测试目标

| 目标类型 | 描述 |
|---------|------|
| 功能正确性 | 验证各模块功能符合设计要求 |
| 性能指标 | 验证系统响应时间、帧率等性能指标 |
| 稳定性 | 验证系统长时间运行的稳定性 |
| 兼容性 | 验证不同硬件配置的兼容性 |
| 安全性 | 验证系统在异常情况下的安全性 |

### 2.2 测试覆盖范围

| 模块 | 单元测试 | 集成测试 | 系统测试 |
|------|---------|---------|---------|
| 抽象层接口 | ✓ | ✓ | ✓ |
| 底盘控制 | ✓ | ✓ | ✓ |
| 机械臂控制 | ✓ | ✓ | ✓ |
| 视觉模块 | ✓ | ✓ | ✓ |
| 状态机 | ✓ | ✓ | ✓ |
| 主循环 | - | ✓ | ✓ |
| 配置管理 | ✓ | ✓ | - |
| Web控制 | - | ✓ | ✓ |

```python
# tests/test_sensor_controller_integration.py
import pytest
```

## 五、系统测试设计

### 5.1 功能测试场景

#### 场景1：网球搜索与跟踪

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 启动机器人 | 机器人进入SEARCH_TENNIS状态 |
| 2 | 放置网球在视野内 | 视觉模块检测到网球 |
| 3 | 机器人旋转搜索 | 检测到网球后进入TRACK_TENNIS状态 |
| 4 | 机器人跟踪网球 | 保持网球在视野中心 |
| 5 | 网球移出视野 | 机器人进入SEARCH_TENNIS状态 |

#### 场景2：网球拾取

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 启动机器人 | 机器人进入SEARCH_TENNIS状态 |
| 2 | 放置网球在近处 | 视觉模块检测到网球 |
| 3 | 机器人接近网球 | 进入APPROACH_TENNIS状态 |
| 4 | 到达拾取位置 | 进入PICK状态 |
| 5 | 机械臂执行拾取 | 夹爪闭合 |

#### 场景3：桶搜索与放置

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 拾取网球后 | 机器人进入SEARCH_BUCKET状态 |
| 2 | 放置桶在视野内 | 检测到桶后进入TRACK_BUCKET状态 |
| 3 | 机器人接近桶 | 进入APPROACH_BUCKET状态 |
| 4 | 到达放置位置 | 进入PUT_BALL状态 |
| 5 | 机械臂执行放置 | 夹爪打开，网球放入桶中 |

### 5.2 性能测试

#### 5.2.1 帧率测试

```python
# tests/test_performance.py
import time
import cv2
from src.camera.usb_camera import USBCamera

def test_frame_rate():
    """测试摄像头帧率"""
    config = {
        'device_id': 0,
        'resolution': (640, 480),
        'frame_rate': 30
    }
    
    camera = USBCamera(config)
    
    start_time = time.time()
    frame_count = 0
    
    # 采集100帧
    while frame_count < 100:
        frame = camera.capture()
        if frame is not None:
            frame_count += 1
    
    elapsed_time = time.time() - start_time
    fps = frame_count / elapsed_time
    
    # 帧率应 >= 25 FPS
    assert fps >= 25, f"帧率 {fps} FPS 低于预期"
    
    camera.release()
```

#### 5.2.2 响应时间测试

```python
# tests/test_response_time.py
import time
from src.state_machine import StateMachine

def test_state_transition_time():
    """测试状态转换响应时间"""
    sm = StateMachine()
    
    observation = {
        'tennis_detected': True,
        'tennis_distance': 0.5,
        'target_offset_x': 0,
        'initialized': True,
        'timestamp': time.time()
    }
    
    start_time = time.time()
    for _ in range(1000):
        sm.transition(observation)
    elapsed_time = time.time() - start_time
    
    # 平均响应时间应 < 1ms
    avg_time = (elapsed_time / 1000) * 1000  # 转换为ms
    assert avg_time < 1.0, f"平均响应时间 {avg_time} ms 超过预期"
```

### 5.3 稳定性测试

```python
# tests/test_stability.py
import time
from src.state_machine import StateMachine

def test_long_running_stability():
    """测试长时间运行稳定性"""
    sm = StateMachine()
    
    observation = {
        'tennis_detected': True,
        'tennis_distance': 0.5,
        'target_offset_x': 0,
        'initialized': True,
```

## 九、测试执行命令

```bash

pytest tests/ -v

# 运行特定测试模块
pytest tests/test_state_machine.py -v

# 生成测试覆盖率报告
pytest --cov=src/ tests/ -v

pytest tests/test_stability.py -v --timeout=3600
```
